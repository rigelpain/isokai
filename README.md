# 位相界 ISOKAI

まったく異なる物理法則の世界を、その法則を見つけて使いながら漂う、ブラウザの探索シミュレーターです（three.js）。

この世界では、重さも引力も時間の速さも**色（位相）**で決まります。あなた自身にも位相があり、同じ法則があなたにもかかります。漂う生き物（漂生体）は、あなたがいなくても光の粒を食べ、互いに喰らい、分裂し、変異し、進化し続けます。

**遊ぶ → https://rigelpain.github.io/isokai/**

## 何が起きる世界か

- **世界の種（seed）ごとに法則の向きが変わります。** ある世界では同じ色どうしが引き合い、別の世界では反発します。結晶のまわりで時間が遅くなる世界もあれば、速くなる世界もあります。前の世界の知識はそのまま通じません
- 法則は全部で 11 個あります。最初はどれも「？？？」で、ヒントしか書かれていません。条件を満たして体験すると、観測手帳に記されます
- 見つけた法則は使えます。空の環と自分の位相の関係が分かれば、位相を回して空を飛べます。位相を放てば、光の粒や生き物を引き寄せたり吹き飛ばしたりできます
- 生態系は進化します。体格・速さ・感覚・肉食度・固有の回転・寿命が遺伝し、分裂のたびに少しずつ変わります。捕食者と被食者の数は波打ち、新しい「形」が生まれては絶滅します。色の揃った群れからは結晶が生まれ、地図が書き換わります。よく通られた地面は沈んで光ります

## 操作

| キー | 動作 |
|---|---|
| クリック | 視点を掴む（ポインタロック）／観測 |
| WASD・矢印 | 移動（Shift で速く） |
| Q / E | 自分の位相（色）を回す |
| Space | 跳ぶ |
| F | 照準の先の漂生体を観測する |
| R | 自分の位相を周りへ放つ |
| Tab | 観測手帳（法則・図鑑・生態グラフ・世界） |
| T | 時間の速さ ×1 / ×3 / ×6 |
| M | 音のオン・オフ |
| B | 光の滲み（ブルーム）のオン・オフ |

URL の末尾 `#数字` が世界の種です。同じ種からは同じ世界が生まれます。見つけた法則と図鑑は、種ごとにブラウザへ保存されます。

## 60fps のための作り

- 漂生体（最大 1600）・光粒（最大 5000）・結晶はすべて typed array で持ち、空間ハッシュ（counting sort）で近傍を引きます。描画は InstancedMesh と Points の数回のドローコールに収まります
- 地形は 1 枚の float テクスチャ（高さ＋踏まれた記憶）を頂点シェーダで読むので、地形を書き換えてもジオメトリは作り直しません
- 後処理は [pmndrs/postprocessing](https://github.com/pmndrs/postprocessing) の Bloom 1 つだけです（効果を 1 パスにまとめられます）
- 品質ガバナー: フレーム時間の移動平均が 18ms を超えると解像度を下げ、それでも重ければブルームを切ります。余裕があれば解像度を戻します
- 手元の計測（Apple Silicon、1280×960、MSAA 4x、漂生体 約 580）では、GPU 完了まで含めて 1 フレーム約 1.2ms（時間 ×6 で約 3.3ms）でした

## 手元で動かす

ビルドは要りません（ES modules と importmap を使っています）。

```bash
python3 serve.py
# → http://localhost:5173
```

## 構成

```
index.html        画面・HUD・importmap（three / postprocessing は CDN）
src/main.js       起動、ループ、入力、法則の発見判定、品質ガバナー
src/laws.js       世界ごとの定数と 11 の法則
src/world.js      世界の組み立て（柱・結晶・光粒・漂生体・空）
src/life.js       漂生体：ゲノム、行動、捕食、位相同期、分裂と変異
src/motes.js      光粒：位相重力で昇り降りする餌
src/crystals.js   結晶：時間の流れを曲げる場
src/terrain.js    記憶する地形（GPU で変位）
src/sky.js        位相の時計である空の環
src/player.js     あなたの体、位相、放射
src/ui.js         観測手帳と位相計
src/audio.js      位相で音程が変わる低いドローン
```
